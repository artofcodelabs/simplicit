Simplicit > Nested components

Same articles + comments as the Model example, but with no Model. Each article-card holds its own comments in this.props and renders one nested comment-item component per comment.

  • Add comment re-renders the card. The morph inserts a new nested child, and Simplicit binds it as a real child instance.
  • 👍 is the comment's own state (this.update on the child). Rename the article or toggle Shout: the likes survive, because a parent re-render doesn't repaint a live nested component.
  • Shout is parent state passed down. The card renders each comment with CommentItem.toHTML({ ...comment, loud }), and those props reach the child through child.update(props).
  • Last liked goes the other way: the child calls this.parent.update(...).
  • 🗑 swaps the row to a different component (deleted-comment) with the same tag and data-key. Simplicit disconnects the old instance and mounts a new one.
