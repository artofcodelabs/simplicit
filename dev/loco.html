Simplicit + Loco-JS-Model — full CRUD

loco-js-model talks to the server (XHR); simplicit holds the in-memory collection and re-renders. One composed class: class Article extends Reactive.

ReadArticle.all() (GET) — fetches and loads into memory
Createnew Article(attrs).save() (POST) — persists and joins the collection
Updaterecord.save({ attrs }) (PUT) — persists and updates memory
Deleterecord.delete() (DELETE) — removes on server and from memory
